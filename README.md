# 🏥 Health Prediction App

An AI-powered health prediction system with robust data validation.

### ✨ Features
- **AI Health Prediction:** Intelligent risk assessment using ai_api.py
- **Data Validation:** Advanced validation for 6 valid & 4 invalid cases
- **Secure Database:** SQLite-based storage
- **Email Validation:** Prevents duplicate entries

### 🛠️ Tech Stack
- Python, Flask / Streamlit, SQLite, Custom AI API

### 🚀 How to Run
git clone https://github.com/kamasanichandravanitha/health-prediction-app.git
pip install -r requirements.txt
python app.py
